# Unity 3D Virtual Environment

## Overview

This project presents a 3D virtual environment developed using Unity. The scene includes interactive objects, architectural structures, and character assets designed to simulate a realistic digital space.

The goal of the project is to demonstrate practical skills in:

* 3D environment design
* Unity scene composition
* asset integration (FBX models, textures, materials)
* lighting and spatial layout
* interactive object configuration
* project organisation suitable for collaborative development

## Technologies Used

* Unity 2022+
* C#
* FBX 3D models
* PBR materials and textures
* Unity Package Manager dependencies

## Project Structure

```
Assets/
Packages/
ProjectSettings/
```

## Features

* fully structured 3D environment
* imported custom 3D assets
* realistic materials and textures
* organised scene hierarchy
* modular object setup
* scalable project architecture

## How to Run

1. Install Unity Hub
2. Open Unity Hub
3. Add project folder
4. Open using Unity 2022 or newer
5. Load the main scene from:

```
Assets/Scenes/
```

## Purpose

This repository is part of a practical exploration of virtual environment design and interactive simulation development using Unity.
